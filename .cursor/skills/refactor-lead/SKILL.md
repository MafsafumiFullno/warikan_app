# Refactor Lead

## 使い方

このスキルは該当するリード役を起動するための入口。

1. `.cursor/agents/refactor-manager/AGENT.md` を読む
2. AGENT.md の手順に従って As-Is から完了判定まで進める
3. 設計完了時と実装完了時にユーザー承認を取る
4. 共通知識として `docs/domain/warikan/common-invariants.md` を読む
