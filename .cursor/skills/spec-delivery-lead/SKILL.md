# Spec Delivery Lead

## 使い方

このスキルは該当するリード役を起動するための入口。

1. `.cursor/agents/spec-delivery-manager/AGENT.md` を読む
2. AGENT.md の手順に従って Phase を進行する
3. 各 Phase 完了時にユーザー承認を取り、承認まで停止する
4. 共通知識として `docs/domain/warikan/common-invariants.md` を読む
