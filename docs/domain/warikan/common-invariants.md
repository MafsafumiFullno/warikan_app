# warikan_app 共通知識（ドメイン不変条件）

このファイルは、割り勘アプリの実装・設計・レビューで共通参照するドメイン知識の正本です。

## ID セマンティクス

- プロジェクトメンバーの API 識別子は `project_member_id` を使う
- `project_members.id` はDBのPKであり、API識別子としては扱わない
- ルートの `{memberId}` は文脈上 `project_member_id` を指す

## 論理削除

- 論理削除は `del_flg` で表現する
- 取得系クエリは `del_flg = false` を前提に組み立てる
- 参照・更新・削除対象の存在確認では、論理削除済みデータを除外して判定する

## フロントエンド API 呼び出し

- フロントエンドの API 呼び出しは `@/lib/api` の `apiFetch` を使う

## 運用メモ

- Rules と Skills で重複記載する場合は、このファイルを正本とし内容を同期する
- 新しいドメイン不変条件を追加する場合は、まずこのファイルに追記してからRules/Skillsへ反映する
